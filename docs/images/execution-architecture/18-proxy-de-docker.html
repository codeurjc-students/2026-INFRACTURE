Infracture · motor de ejecución · ADR 0013

El backend solo llega a Docker a través del proxy

El backend no monta el socket de Docker. Envía sus llamadas a docker-proxy, un HAProxy oficial con una lista cerrada de método y ruta. Lo que no está en la lista recibe 403 y nunca llega al motor. Los contenedores del experimento no ven ni el proxy ni el socket.

1contenedor monta el socket: docker-proxy, en solo lectura
0puertos publicados por el proxy y por el experimento
403para cualquier llamada que no esté en la lista
ARQUITECTURA

Dónde está el proxy

El punto verde es una llamada permitida que cruza el proxy hasta el motor y crea la red del experimento. El punto rojo es un exec que el proxy corta con 403.
