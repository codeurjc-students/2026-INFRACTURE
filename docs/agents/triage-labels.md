# Triage labels

Use these mappings when an explicitly invoked skill classifies issues.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs evaluation |
| `needs-info` | `needs-info` | Needs more information |
| `ready-for-agent` | `ready-for-agent` | Sufficiently specified for possible delegation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

`ready-for-agent` describes readiness, not permission to implement. The student chooses manual, paired or delegated work per issue or slice. It does not prevent manual implementation.

These mappings document the vocabulary; they do not establish that every label exists remotely. Check existing labels before authorized changes and reuse matching names. Creating or applying labels follows [tracker authorization rules](issue-tracker.md).
